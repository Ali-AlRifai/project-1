BLINQPAY LANDING PAGE

Open index.html in your browser. No installation or build step is needed.

index.html: semantic page structure and content
style.css: styling, colors, and responsive layouts
assets/: images extracted from the supplied reference and the hero curve

Pure HTML and CSS; no JavaScript or frameworks.
Breakpoints: 1100px (tablet), 760px (mobile).

The supplied reference is only 261 x 781 pixels. Its extracted image assets
will appear soft at larger sizes. Replace the matching files in assets with
original Figma exports for sharper visuals. Some small text is reconstructed
because it is not legible in the reference.

Buttons link to page sections or draft an email. This is a visual landing
page; payment processing and sign-in are not implemented.
Contact email addresses and social links are placeholders; replace them
with your real links before using this page for a business.
